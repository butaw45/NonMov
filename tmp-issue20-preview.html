Provider Global

Pool penyedia untuk semua judul (kecuali ada override per judul). Contoh config.json hasil dari form ini di bawah.

viduki API 2 templateMovie + TV https://www.viduki.net/2/movie/{tmdb_id} https://www.viduki.net/2/tv/{tmdb_id}/{season}/{episode}
videasy templateMovie + TV https://player.videasy.net/movie/{tmdb_id} https://player.videasy.net/tv/{tmdb_id}/{season}/{episode}
2embed templateMovie https://www.2embed.cc/embed/{tmdb_id}
